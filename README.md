# Meta Muse — R1 Launcher

A Rabbit R1 creation that opens [muse.ai](https://muse.ai) in the R1 browser.

Tap the creation, watch the portal, and it auto-launches Muse after 4 seconds
(or tap **ENTER MUSE** to go instantly). Sign in once — whether the R1 keeps
you signed in between opens depends on muse.ai's session and the R1 browser's
cookie persistence, which no creation page can control.

Styled for the R1's 240×282 screen: animated Muse avatar (the steampunk robot)
in a glowing alien portal, starfield, neon green/cyan HUD rings.

Install on the R1: creations card → create tab → "add via QR code" → scan the
creation code.
